# New UI Shell — Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A switchable "New" interface in the real editor: a token theme, the new shell hosting every existing panel, and a fully redesigned Group Addresses view, usable on the user's own project on the desktop and in `--web`.

**Architecture:**
- A second hello_imgui docking layout "New" holds one `###shell` window. It custom-draws the top bar, sidebar, list column and tab strip.
- Existing `PanelDefinition`s render unchanged inside child regions.
- The shell talks to the app only through a `ShellHost` protocol.
- Group-address edits go through `ProjectService` with undo.
- A token module feeds the new XKNX themes.

**Tech Stack:** Python 3 (uv workspace), imgui-bundle 1.93 / hello_imgui, pyright strict, ruff, pytest; Playwright 1.64.0 via `uv run --with` (screenshots only).

**Spec:** `docs/superpowers/specs/2026-11-24-ui-shell-m1-design.md` (parent: `docs/superpowers/specs/2026-11-24-gui-redesign-design.md`; visual reference: `docs/design/prototype/`; rules: `.agents/skills/gui-design/`).

## Global Constraints

- **Classic is unchanged.** The default interface stays Classic, with the same themes, layout, menus and status bar. Every Classic test stays green, unmodified.
- **AGENTS.md rules apply in full:**
  - `uv run` for everything; 2-space indentation; pyright strict; ruff.
  - UI texts are English msgids in `strings.py`, in title case or sentence case, with plural forms. Every language's `.po` file is updated and compiled with `uv run --with babel pybabel compile -d <dir> -D <domain>`.
  - Every new user-visible or editable thing gets MCP access through the same service method, with a docstring and tests. Tools are declared `@tool("read"|"write"|"destructive")` and pass `test_addressing.py`.
  - Every new CLI option is documented in `cli.py` help and in the README "Command Line" table.
  - Browser UI rules: `file_dialogs`, `os_open`, no OS dialogs, imgui clipboard, touch reachability, narrow layouts.
- **Colors** come only from `widgets/tokens.py` (and `theme.py`), enforced by `tests/test_design_tokens.py`. **Spacing** comes from `tokens.space()`. **Type** comes from `tokens.font(style)`, with at most three sizes per view.
- **Token values** are copied verbatim from `.agents/skills/gui-design/design-system.md` and must stay identical.
- **No list-row inputs**, except the inline name rename after a double-click or F2.
- **Never hover-only.** A long press of 500 ms counts as a right click. The mouse wheel never changes a value.
- **Breakpoints in the shell:** ≥ 1000 full; 600–999 sidebar as icons, list as a drawer; < 600 drill-down with a back button and the navigation as a drawer.
- **The shell never imports `editor_gui.main`.** It gets everything through `ShellHost`.

## Review Focus

1. **Switching interfaces back and forth** (setting and `--interface`) on the desktop and in `--web`. Expected: Classic comes back with its layout intact, and nothing from New leaks into Classic (menus, status bar, theme). The test belongs in Task 4.
2. **A project whose GA style forbids middle groups (two-level) or uses free style.** Expected: "+ Neu ▾" offers only the allowed kinds, the validator returns `style_forbids`, and there is no crash. The test belongs in Tasks 7 and 9.
3. **Large projects** (2 000+ GAs, 300+ devices). Expected: tree and tables use clipping, the filter stays responsive, and nothing is rebuilt per frame without caching on `ProjectService.revision`. The test belongs in Task 9 (generated fixture, render time bound).
4. **No project open, or a project closed while tabs are open.** Expected: the shell shows an empty state with Open and New, its tabs close, and there are no exceptions. The test belongs in Task 6.
5. **Undo/redo after shell edits** (rename, quick create, address change). Expected: one undo step per edit, the tree and tabs follow undo, and a tab whose object disappears closes. The tests belong in Tasks 7 and 10.
